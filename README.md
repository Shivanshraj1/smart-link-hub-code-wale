# smart-link-hub-code-wale

\# 🔗 Smart Link Hub



A full-stack Smart Link Hub that allows users to create a single shareable page

containing multiple tracked links with analytics.



Built for hackathon submission 🚀



---



\## ✨ Features

\- Create a personal link hub

\- Add multiple links under one hub

\- Track total visits per hub

\- Track clicks per individual link

\- Clean frontend UI

\- MongoDB persistence



---



\## 🛠 Tech Stack

\- \*\*Frontend:\*\* React (Create React App)

\- \*\*Backend:\*\* Node.js, Express

\- \*\*Database:\*\* MongoDB Atlas

\- \*\*Deployment:\*\* Render (Backend), Vercel (Frontend)
